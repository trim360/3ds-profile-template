Hébergement statique

Ce site ne possède pas de backend d’édition. Les visiteurs peuvent le consulter normalement. Pour le modifier, ouvre setup.bat sur Windows ou setup.sh sur Linux.

Pour activer l’édition en ligne, configure le compte local avec l’option o de setup, puis démarre le backend indiqué dans la documentation.

Compte à configurer en local

Le compte ne peut pas être créé depuis une page publique. Sur l’ordinateur qui héberge le site, lance setup et choisis l’option o.

Récupération locale

Aucun e-mail de réinitialisation n’est envoyé. Seule une personne ayant accès aux fichiers du serveur peut réinitialiser le compte.

Ouvre setup, choisis o puis confirme la réinitialisation. Tu peux aussi lancer :

node scripts/owner.mjs reset

Les profils et médias sont conservés ; les anciennes sessions deviennent invalides.
