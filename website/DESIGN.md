# Project showcase direction

Modern presentation of the existing Nintendo 3DS-inspired personal website.
ENERGY 2 / RHYTHM 3 / MOTION 2. Direction supplied by Trim's showcase brief.

The reference 3dsDL was inspected in the browser: compact navigation, strong
product illustration, feature tour, installation choices and concise questions.
We retain its product-first approach, not its blue stripes, console illustration,
fonts, text, testimonials, badges or exact composition.

Warm ivory and olive come from the actual template. Burnt orange highlights
the next action and recalls its Nintendo Network mark. The original settings
wrench identifies the project; Nintendo asset notices remain separate.
Trebuchet MS gives headings a rounded, console-adjacent voice, with system sans
for readable prose. No remote font requests or icon library.

A split introduction uses a real screenshot as the focal point. The feature
tour changes between real screens; supporting capabilities form a plain ruled
list. A screenshot gallery, dark olive demo invitation, OS-specific instructions,
community note and native FAQ provide different compositions for different jobs.
Only screenshot frames lift off the page. Small button bevels echo hardware;
there are no glow effects or decorative status badges.

Motion is limited to one-time screenshot reveals, tab changes and short hover
responses. No autoplay carousel, scroll hijacking or perpetual movement.
Reduced motion removes transitions. Narrow navigation becomes a labelled Menu;
the hero and installation columns stack before their text becomes cramped.

## Visual refinement, 27 October 2026

Reading this as: an existing fan-project showcase for people personalizing a
website, with warm console materials; ENERGY 2 / RHYTHM 3 / MOTION 2 unchanged.
All text, links, section order, screenshots and functionality are retained.

- Ivory and olive preserve the settings-screen identity; burnt orange still
  marks the main action. Headline line one anchors the message in dark ink.
- Rounded Trebuchet headings retain the console character without new fonts;
  reduced tracking and balanced wrapping improve both languages.
- The screenshot's inset rim and restrained lower shadow distinguish the
  product preview from surrounding content, without rotating its contents.
- Shallow button bevels express a press; gradients are confined to physical
  button surfaces and the hero rim, not page decoration.
- Features share one pale enclosure to connect the actual tabs and preview;
  supporting capabilities stay plain text divided by the template's dotted rule.
- Gallery frames alternate their vertical offset only on wide screens to
  separate successive captures, while preserving reading and keyboard order.
- The dark demo band, flat source links, dotted community row and ruled FAQ
  give different content different compositions, without changing section order.
- Installation instructions have their own quiet surface; the dark command
  strip makes the real command easy to locate, with its existing copy action.
- Image reveals reuse the existing one-time observer; text arrives once, and
  native FAQ answers fade briefly. Motion changes opacity and transform only,
  has no loop or scroll interception, and is disabled for reduced motion.

Reference studied: [3dsDL](https://ankush.one/3dsDL/) and its
[site source](https://github.com/ankushKun/3dsDL/tree/main/site).
`index.html`, `styles.css`, `app.js`, `fonts.css`, site README and root LICENSE
were retrieved on 27 October 2026. The reference uses plain HTML/CSS/JS,
self-hosted M PLUS Rounded 1c / M PLUS 1 Code / DotGothic16 / Gaegu (SIL OFL),
and a vendored MIT QR-code library. Root code license: GPLv3. Console imagery
has separate CC BY 4.0 and Nintendo notices in its README.

Useful principles: rounded legible hierarchy, compact section navigation,
shallow control depth, real product imagery, content-driven breakpoints and
progressive animation gated by reduced motion. Its drifting backdrop, console
photographs, handwritten annotations, sound system, auto-cycling screens,
testimonials and QR dependencies are not used. No reference code, fonts or
artwork is redistributed in this refinement.
